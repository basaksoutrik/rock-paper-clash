# ✦ Rock Paper Scissors

A simple **Rock Paper Scissors** game written in **C**.

## 🎮 About

This is a beginner-friendly console game where the player competes against the computer.

The computer randomly chooses **Rock, Paper, or Scissors**, and the winner is determined according to the classic rules.

## ✨ Features

* 👤 Player vs Computer
* 🎲 Random computer choice
* 🪨 Rock
* 📄 Paper
* ✂️ Scissors
* 🏆 Win / Lose / Draw detection
* 🔢 Score tracking

## 🛠️ Technologies Used

* **C**
* Standard C Library

## ▶️ How to Run

Compile the program:

```bash
gcc main.c -o rock-paper-scissors
```

Run it:

```bash
./rock-paper-scissors
```
